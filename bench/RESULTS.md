## Scenarios

| Scenario                  | Operation timed                                                                           |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| `write.initial`           | Write the ~3.3k-entity dashboard query into a fresh cache                                 |
| `write.refetch`           | Write the dashboard again (a refetch or poll) into the cache holding it, one task changed |
| `read.hit`                | readQuery of the unchanged dashboard (result cache hit)                                   |
| `read.afterWrite`         | Toggle one task, then readQuery the whole dashboard                                       |
| `read.variables`          | readQuery of 20 parameterized queries, fresh variables objects each time                  |
| `union.write`             | Write a 1.5k-item feed through interface/union fragments (possibleTypes)                  |
| `union.afterWrite`        | Change one feed item, then readQuery the 1.5k-item union feed                             |
| `policies.paginate`       | offsetLimitPagination merge: write 20 pages of 100, then read the 2k list                 |
| `policies.read`           | Toggle one task, then read 1k tasks through a read function, plus a cache redirect        |
| `policies.keyArgs`        | Write page 1 of a keyArgs field (50 items), then read it back as page 2                   |
| `watch.broadcast`         | 50 watched project queries; rename one user (affects a few watches)                       |
| `gc.orphan`               | Replace one project's 20 tasks (orphans 60 entities) in the dashboard, then collect       |
| `gc.cycle`                | Replace a 200-node cyclic cluster next to the dashboard (unreachable cycle), then collect |
| `diff.partial`            | diff (returnPartialData) of the dashboard plus a missing field, unchanged cache           |
| `diff.partial.afterWrite` | Toggle one task, then diff (returnPartialData) of the partial dashboard                   |
| `modify.read`             | cache.modify one task field, then readQuery the dashboard                                 |
| `extract`                 | extract() the dashboard cache                                                             |
| `restore`                 | restore() an extracted dashboard snapshot into a fresh cache, then read it                |
